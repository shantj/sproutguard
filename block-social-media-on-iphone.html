How to Block Social Media on iPhone

If social media keeps eating your evenings, the mistake is usually not that iPhone cannot block it. The mistake is blocking only the app, while Safari, mobile domains, and the settings screen are still wide open.

Short answer: use Apple's free Screen Time tools to block both the apps and the websites. If you want the same setup wrapped in sessions and a streak, SproutGuard adds that on-device with no account.

First: the four ways social media blocks fail

  1. You blocked the app, not the website. Instagram, TikTok, Reddit and YouTube all still have browser routes.
  2. You used App Limits without real danger-hour coverage. The block arrives after the damage is already done.
  3. Settings are unlocked. The same distracted version of you who wants the feed can remove the block in seconds.
  4. You blocked a brand, not the exact routes you use. Mobile domains and shared links still slip through.

1. Block the social apps themselves

For a broad social-media block, the simplest built-in move is Settings → Screen Time → App Limits, then choose Social or the specific apps you want to cut off. Set the limit low enough that it behaves like a wall rather than a suggestion.

If the problem is time-of-day specific, Downtime is often better than App Limits. It blocks on a schedule instead of waiting for you to consume the daily allowance first.

2. Block the matching websites in Safari

  1. Open Settings → Screen Time → Content & Privacy Restrictions
  2. Tap Content Restrictions → Web Content
  3. Choose Limit Adult Websites
  4. Add each social site you actually use under Never Allow

Examples: instagram.com, tiktok.com, reddit.com, youtube.com, m.youtube.com, x.com.

3. Lock Screen Time Settings

Use Lock Screen Time Settings and set a passcode that is not muscle memory. Without this, the block is real only until the first tired evening.

Important: if you can remove the restriction in ten seconds, you do not have a blocker. You have a postponed decision.

4. Test every route you actually relapse through

  • Open the app directly
  • Open the site in Safari
  • Open a shared link from Messages or Mail
  • Try the mobile domain if the service uses one

If one still works, your brain will remember it. Fix it immediately instead of promising yourself you will not use it later.
