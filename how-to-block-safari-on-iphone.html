How to Block Safari on iPhone

If the browser itself is the problem, blocking only Instagram or Reddit is not enough. You close one icon, then open the same habit in Safari five minutes later. iPhone can shut Safari off completely — but that is a bigger move than blocking a few websites, so it is worth choosing the right wall.

Short answer: Apple's built-in Screen Time can disable Safari for free. If you still need a browser but want distracting sites wrapped in sessions and a streak, SproutGuard adds that on-device with no account.

First: decide whether you need to block Safari or just specific sites

  1. Block Safari itself if the browser is the relapse route and you keep opening whatever feed is available.
  2. Block websites instead if you still need Safari for normal life but want certain domains gone.

Most people should start with the lighter move. Blocking Safari entirely is strong, but it also removes a general-purpose tool you may still need.

1. Turn on Screen Time restrictions

  1. Open Settings → Screen Time
  2. Tap Content & Privacy Restrictions and turn it on

This is the switch that exposes the controls for disabling built-in apps like Safari.

2. Disable Safari under Allowed Apps & Features

  1. Inside Content & Privacy Restrictions, open Allowed Apps & Features
  2. Find Safari and turn it off

Safari disappears from the phone until you allow it again. That is the cleanest built-in way to block the browser itself without deleting anything.

3. Close the obvious browser escape hatches

Disabling Safari does not disable the entire web.

  • Other browsers like Chrome or Firefox can still work if they are installed.
  • New installs can recreate the problem if App Store installs are still open.
  • In-app browsers inside messaging or social apps can still open links.

If the browser itself is the habit, add the missing guardrails too: block other browsers you use, and if reinstalling is your fallback, use Content & Privacy Restrictions → iTunes & App Store Purchases → Installing Apps → Don't Allow.

4. Lock Screen Time Settings

Go back to Screen Time → Lock Screen Time Settings and set a passcode. Without this, you have not really blocked Safari. You have only added one extra tap before turning it back on.

Without a passcode, the block is advisory. You are asking the same distracted version of yourself who wants the browser to also protect the settings screen. That arrangement usually lasts until the first tired evening.

5. If you only need some sites gone, block websites instead

If Safari is useful for work or life, disabling the whole browser is often too blunt. In that case, keep Safari and block the distracting domains under Web Content restrictions.
