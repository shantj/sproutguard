How to Block Reels on iPhone

The honest answer first: you cannot remove only the Reels tab with iPhone's built-in tools. What you can do is stop Instagram and Facebook Reels in practice by blocking every way the feed reaches you.

Everything below can be done free with iPhone's own Screen Time. If you want the same system-level block wrapped in a session and a streak, SproutGuard does that on-device with no account.

What iPhone can and cannot block

Screen Time works at the app and website level. That means it can block Instagram, Facebook, instagram.com, and facebook.com. It cannot say "allow Instagram, but hide Reels" or "allow Facebook, but remove only short-form video." So if Reels is the problem, the reliable move is to block the whole app during the hours where you lose control.

If you want to keep Instagram or Facebook fully available on iPhone while removing only Reels, there is no clean system-level switch for that today. Any guide that implies otherwise is usually talking about a fragile account setting or a browser workaround that disappears the moment you open the app again.

The setup that actually works

1. Block Instagram and, if needed, Facebook

  1. Open Settings > Screen Time > App Limits > Add Limit.
  2. Choose Social and select Instagram. If Facebook Reels is part of the same habit loop, select Facebook too.
  3. Set the limit to 1 minute.
  4. Tap Add.

This is the part that stops Reels inside the apps, because it stops the whole apps.

2. Block the browser routes too

  1. Go to Settings > Screen Time > Content & Privacy Restrictions and turn it on.
  2. Open Content Restrictions > Web Content > Limit Adult Websites.
  3. Under Never Allow, add instagram.com, facebook.com, and m.facebook.com.

If you skip this, the habit simply migrates from the app to Safari or to a shared link someone sent you.

3. Put a passcode behind the override

Go to Settings > Screen Time > Lock Screen Time Settings and set a passcode you do not know by reflex. Without this, every block offers "Ignore Limit" and the whole setup turns decorative.

4. Add Downtime over the hours that actually break you

If Reels is a bedtime problem, set Downtime for bedtime. If it is first thing in the morning or during work breaks, set it there instead. Narrow windows survive better than all-day lockdown because they feel accurate rather than punitive.

If the problem is short-form video in general

That last row matters. Many people do block Reels successfully and then simply migrate to TikTok or YouTube Shorts. If what actually owns your attention is vertical short-form video, not Instagram or Facebook as brands, then the durable fix is blocking that whole category during your danger hours.
