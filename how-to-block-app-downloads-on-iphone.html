How to Block App Downloads on iPhone

If deleting Instagram, TikTok, Reddit, or YouTube only buys you one evening, the weak point is often not the block itself. The weak point is that reinstalling from the App Store still takes fifteen seconds.

Short answer: use Apple's free Screen Time restrictions to set Installing Apps to Don't Allow. If you want that wrapped in focus sessions and a streak, SproutGuard adds that on-device with no account.

First: when this setting matters

  1. You delete an app instead of blocking it. The icon disappears, but the App Store brings it back immediately.
  2. Your block works until the first bad evening. Reinstalling is easier than undoing the habit.
  3. Your session survives the reinstall. So the friction is close to zero.
  4. Screen Time settings are unlocked. So the install restriction itself can be removed in seconds.

If that sounds familiar, blocking downloads is not a side setting. It is the missing half of the wall.

1. Turn on Screen Time restrictions

  1. Open Settings → Screen Time
  2. Tap Content & Privacy Restrictions
  3. Turn the switch On

This unlocks the App Store purchase restrictions menu. Without this, the install button stays open no matter how disciplined the rest of the setup looks.

2. Block app installs

  1. Go to iTunes & App Store Purchases
  2. Tap Installing Apps
  3. Choose Don't Allow

That is the exact setting that stops new installs and reinstalls from the App Store. It is the cleanest fix for the "I deleted it and redownloaded it ten minutes later" loop.

3. Lock Screen Time Settings

Use Lock Screen Time Settings and set a passcode you do not know reflexively. Otherwise the same tired version of you who wants the app back can reopen installs almost immediately.

If the install restriction can be removed in ten seconds, you do not have a block. You have a speed bump.

4. Test the App Store before you need it

  • Open the App Store
  • Search for the app you usually reinstall
  • Tap the download cloud or Get button
  • Verify that installing is blocked rather than counting on yourself later

If the install still goes through, the usual causes are that Content & Privacy Restrictions is off, Installing Apps is still set to Allow, or Screen Time settings were never locked.

What this setting does not do

It does not remove apps already installed. It does not block websites in Safari. It does not stop you from opening what is already on the phone. Think of it as the anti-reinstall layer, not the whole system.

The durable setup is usually: block the app, block the website if one exists, block installs so deletion is not an escape hatch, and lock Screen Time settings with a passcode.
